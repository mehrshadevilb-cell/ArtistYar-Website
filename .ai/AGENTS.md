# ArtistYar AI Engineering Agents

## Active Agents

- Frontend Architect Agent: Next.js, React, TypeScript architecture.
- UI Motion Agent: premium animations, AI-first interaction design.
- Performance Agent: Core Web Vitals, optimization, bundle analysis.
- SEO Agent: metadata, indexing, content structure.
- Review Agent: quality and maintainability checks.

## Rules

- Keep premium AI product identity.
- Prefer reusable components and design systems.
- Preserve accessibility and performance.
- Validate changes before release.


## UI Enhancement Skills
- motion-3d-ui-engineering: use for Motion, GSAP/ScrollTrigger, Lenis, CSS 3D and R3F/Three.js decisions.
- ui-debug-audit: mandatory visual/interaction/performance QA for UI changes.
- frontend-design-pro-tailwind: preserve the established visual system and responsive design.
- react-ui-patterns + react-best-practices: component architecture and interaction patterns.
- nextjs-best-practices + nextjs-app-router-patterns: Next.js App Router correctness.
- web-quality-audit: release-level web quality checks.

## Motion Stack
The project uses Motion for React micro-interactions, GSAP/ScrollTrigger for advanced scroll timelines, Lenis for smooth scrolling, and Three.js/R3F/Drei for isolated 3D scenes. Do not use all libraries indiscriminately; select the smallest appropriate tool per interaction.
